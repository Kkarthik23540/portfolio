# 🌐 Portfolio Website

A modern, responsive, and interactive portfolio website built using HTML, CSS, JavaScript, and Vite.

## 🚀 Overview

This project showcases a professional portfolio website with a clean design, responsive layout, smooth navigation, and interactive features.

## ✨ Features

- Responsive Design
- Mobile Navigation Menu
- Smooth Scrolling
- Scroll Reveal Animations
- Skills Showcase
- Projects Section
- Education Timeline
- Certifications Section
- Contact Form Validation
- Back-to-Top Button
- Vercel Web Analytics

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Vite
- Vercel Web Analytics

## 🧑‍💻 Local Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`. Vercel deploys the generated `dist/` directory.
